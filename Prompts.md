# TaskMatrix – AI Architecture Prompts

## Project Overview

TaskMatrix is a full-stack Agile Project Management Platform designed to help software teams manage workspaces, projects, tasks, deadlines, and team collaboration.

**Development Track:** Full Stack Development

## 1. Project Selection and Scope

**Prompt:**

I am a Full Stack Developer working on a five-week capstone project. Suggest a practical and scalable project idea that demonstrates frontend and backend development skills. Explain the core features, user roles, and MVP scope for an Agile Project Management Platform named TaskMatrix.

## 2. Technology Stack Selection

**Prompt:**

Suggest a suitable technology stack for building TaskMatrix as a full-stack application. Consider Next.js, JavaScript, Tailwind CSS, Shadcn UI, Redux Toolkit, Node.js, Express.js, MongoDB Atlas, Mongoose, JWT, Socket.IO, and Vercel. Explain the purpose of each technology.

## 3. Database Architecture

**Prompt:**

Design a MongoDB database architecture for TaskMatrix using five main collections: Users, Workspaces, Projects, Tasks, and ActivityLogs. Identify important fields, ObjectId references, and relationships. Explain how workspace members and their roles can be stored efficiently.

## 4. Authentication and Authorization

**Prompt:**

Explain how to implement secure user authentication and Role-Based Access Control (RBAC) in TaskMatrix using JWT and bcrypt. Define the responsibilities of Administrator, Project Manager, and Team Member.

## 5. Backend API Architecture

**Prompt:**

Design RESTful API endpoints for TaskMatrix. Include authentication, workspace management, project management, task CRUD operations, task assignments, and activity tracking. Explain suitable HTTP methods and authorization requirements.

## 6. UI/UX Design

**Prompt:**

Suggest a modern, professional SaaS dashboard design for TaskMatrix. Define the layout and important components for three screens: Login/Register, Main Dashboard, and Project Details with a Kanban Board. Follow responsive design principles.

## 7. Real-Time Collaboration

**Prompt:**

Explain how Socket.IO can be integrated into TaskMatrix to provide real-time task updates, status changes, and team collaboration. Suggest a basic event architecture.

## 8. Security and Validation

**Prompt:**

Identify important security practices for TaskMatrix, including password hashing, JWT validation, role-based authorization, input validation, error handling, and protection of sensitive environment variables.

## 9. Testing and Deployment

**Prompt:**

Suggest a practical testing and deployment strategy for TaskMatrix. Explain how to test REST APIs using Postman and deploy the frontend and backend using Vercel and Render.

## 10. AI-Assisted Development Approach

AI assistance is used for project planning, technical research, database design, architecture decisions, and development guidance. All suggested solutions are reviewed and validated before implementation.
